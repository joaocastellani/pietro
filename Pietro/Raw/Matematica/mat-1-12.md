## Função afim — definição

Uma **função afim** é toda função da forma:

**f(x) = ax + b**, onde a e b são números reais e **a ≠ 0**

| Coeficiente | Símbolo | Significado |
|-------------|---------|-------------|
| **Angular** | a | Taxa de variação (inclinação da reta) |
| **Linear** | b | Ponto onde a reta cruza o eixo f(x) |

**Exemplos de funções afim:**
- f(x) = 2x + 1 (a=2, b=1)
- f(x) = –x + 10 (a=–1, b=10)
- f(x) = –5x + 1 (a=–5, b=1)
- f(x) = 3x + 9 (a=3, b=9; equivale a 3x + 3²)

**Exemplos que NÃO são funções afim:**
- f(x) = –32 (a=0; função constante)
- f(x) = x² + 2x – 1 (grau 2; não é afim)

### Frente A — exemplo introdutório
Bruno precisa formatar o computador. Assistência técnica: R$ 50,00 inicial + R$ 25,00/hora.

**Lei de formação:** f(t) = 50 + 25t
- t = horas trabalhadas (variável independente)
- f(t) = custo total (variável dependente)

## Gráfico de uma função afim (págs. 300–305)

O gráfico de uma função afim é **sempre uma reta não perpendicular ao eixo x**.

### Passos para construção:
1. **Atribuir valores a x** e calcular f(x) → montar tabela com pares (x, f(x))
2. **Marcar os pontos** no plano cartesiano e ligá-los

> Para traçar o gráfico, bastam **dois pontos** (a reta fica determinada).

### Exercício resolvido 1 — f(x) = –3x – 2 (pág. 301)

| x | f(x) = –3x – 2 | (x, f(x)) |
|---|----------------|-----------|
| –2 | –3(–2) – 2 = 4 | (–2, 4) |
| –1 | –3(–1) – 2 = 1 | (–1, 1) |
| 0 | –3(0) – 2 = –2 | (0, –2) |
| 1 | –3(1) – 2 = –5 | (1, –5) |
| 2 | –3(2) – 2 = –8 | (2, –8) |

## Funções crescente, decrescente e constante (págs. 306–307)

| Tipo | Condição | Comportamento do gráfico |
|------|----------|--------------------------|
| **Crescente** | a > 0 | Reta sobe da esquerda para a direita |
| **Decrescente** | a < 0 | Reta desce da esquerda para a direita |
| **Constante** | a = 0 | Reta horizontal (paralela ao eixo x) |

Para funções constantes (a = 0):
- b > 0: reta acima do eixo x
- b = 0: reta sobre o eixo x
- b < 0: reta abaixo do eixo x

> Como o gráfico é uma reta, pode ser traçado conhecendo **apenas dois pontos**.

## Função linear — caso particular (págs. 308–309)

A **função linear** é uma função afim com **b = 0**:

**f(x) = ax** (a ≠ 0)

- O gráfico **passa pela origem** do plano cartesiano (0, 0)
- É um caso particular da função afim

### Exemplo: Guilherme, vendedor de videogames
Guilherme recebe R$ 250,00 por console vendido. Lei: f(x) = 250x

| Mês | Consoles vendidos (x) | Salário f(x) = 250x (R$) |
|-----|-----------------------|--------------------------|
| Fevereiro | 5 | 1.250 |
| Março | 7 | 1.750 |
| Abril | 9 | 2.250 |
| Maio | 10 | 2.500 |
| Junho | 12 | 3.000 |
| Julho | 15 | 3.750 |

Análise: função crescente (a=250>0); salário de R$ 4.500 corresponde a 18 consoles (coordenada (18, 4500)).

## Características do gráfico de uma função afim (pág. 310)

Para f(x) = ax + b:

- **Coeficiente linear b = ordenada da interseção com o eixo f(x)**:
  O gráfico cruza o eixo vertical em (0, b), pois f(0) = a·0 + b = **b**

- **Interseção com o eixo f(x) = coeficiente linear b da função**

> Em todo gráfico de uma função afim, a intersecção entre a reta e o eixo f(x) é o coeficiente linear (b) da função.

## Zero de uma função afim (págs. 310–311)

O **zero** (ou raiz) de uma função é o valor de x para o qual **f(x) = 0** — o ponto onde a reta cruza o eixo x.

**Para encontrar:** resolver a equação f(x) = 0 → ax + b = 0 → **x = –b/a**

### Exercício resolvido 3 — f(x) = –3x + 9 (pág. 311)
0 = –3x + 9 → 3x = 9 → **x = 3**

## Reconhecendo se um gráfico representa uma função (págs. 311–312)

- Se cada reta toca o gráfico em **no máximo 1 ponto** → representa uma função ✅
- Se alguma reta toca em **2 ou mais pontos** → NÃO representa uma função ❌

## Encontrando a lei de formação de uma função afim (págs. 314–317)

A partir do gráfico ou de dois pares ordenados, encontrar f(x) = ax + b.

### Método (5 passos):
1. **Identificar dois pares ordenados** do gráfico (ex.: pontos destacados ou interceptos)
2. **Escrever as equações** do 1º grau: f(par1) → ax₁ + b = y₁; f(par2) → ax₂ + b = y₂
3. **Montar o sistema** de equações
4. **Resolver** pelo método da substituição ou adição
5. **Escrever a lei** f(x) = ax + b

### Caso especial — coeficiente angular a partir do gráfico:
Se conhecido o par (x₁, y₁), calcular a como razão entre as medidas dos eixos:
- a = variação de f(x) / variação de x = Δy/Δx

### Exercício resolvido 5 — Lei a partir de dois pontos do gráfico (pág. 317)

- (1/3, 0): 0 = a/3 + b → (I)
- (0, –1): –1 = b → (II)

{0 = a/3 + b | (I)

**4º passo:** b = –1; substituindo em (I): 0 = a/3 – 1 → a = 3

**5º passo:** **f(x) = 3x – 1**

## Síntese do capítulo (pág. 335)

### Diagrama (imagem: mat-1-12-sintese.png)
Mapa conceitual com os seguintes ramos a partir de "Função afim":

1. **Definição:** f(x) = ax + b (coeficiente angular a; coeficiente linear b)
2. **Caso particular — função linear:** f(x) = ax (b = 0; passa pela origem)
3. **Gráfico:** crescente (a>0), decrescente (a<0), constante (a=0); traçado com 2 pontos
4. **Zero da função afim:** valor de x em que a reta intersecta o eixo x → resolver f(x) = 0
5. **Reconhecer se gráfico é/não é função:** teste da reta vertical
6. **Encontrar lei de formação:** ler 2 pares ordenados → sistema de equações → resolver para a e b
7. **Domínio e imagem:** domínio = eixo x (abscissas); imagem = eixo y (ordenadas)
