## Frente A — Plano cartesiano

### Definição

O **plano cartesiano** é um sistema de coordenadas formado por dois eixos perpendiculares:
- **Eixo das abscissas** (eixo x) — horizontal
- **Eixo das ordenadas** (eixo y) — vertical

Os dois eixos dividem o plano em **quatro quadrantes**.

### Representação de pontos

Cada ponto P é representado por um **par ordenado (x, y)**, onde:
- x = abscissa (distância ao eixo y)
- y = ordenada (distância ao eixo x)

| Quadrante | Abscissa | Ordenada |
|-----------|----------|----------|
| 1º | positiva (+) | positiva (+) |
| 2º | negativa (–) | positiva (+) |
| 3º | negativa (–) | negativa (–) |
| 4º | positiva (+) | negativa (–) |

**Casos especiais:**
- Ponto no eixo x: ordenada = 0, forma P(x, 0)
- Ponto no eixo y: abscissa = 0, forma P(0, y)

## Distância entre dois pontos

### 1º caso — Pontos com mesma ordenada (y_A = y_B)

Os pontos A e B estão sobre uma reta horizontal.

**d_AB = |x_B – x_A|**

### 2º caso — Pontos com mesma abscissa (x_A = x_B)

Os pontos A e B estão sobre uma reta vertical.

**d_AB = |y_B – y_A|**

> **Observação:** A distância é sempre não negativa — por isso usamos módulo (valor absoluto).

### 3º caso — Pontos com ordenada e abscissa distintas (caso geral)

Dados A(x_A, y_A) e B(x_B, y_B) quaisquer, formamos o triângulo retângulo ACB onde:
- C = (x_B, y_A) — ponto auxiliar
- Cateto horizontal: AC = |x_B – x_A|
- Cateto vertical: CB = |y_B – y_A|
- Hipotenusa: AB = d_AB (distância procurada)

Aplicando o **Teorema de Pitágoras**:

**(d_AB)² = (x_B – x_A)² + (y_B – y_A)²**

**d_AB = √[(x_B – x_A)² + (y_B – y_A)²]**

> Esta fórmula também funciona para os casos 1 e 2 (quando uma das diferenças é zero).

## Exercício Resolvido 1

**Calcule a distância entre os pontos M(2, 5) e T(5, –1).**

**Resolução:**
d_MT = √[(5 – 2)² + (–1 – 5)²]
d_MT = √[3² + (–6)²]
d_MT = √[9 + 36]
d_MT = √45
**d_MT = 3√5**

## Exercício Resolvido 2

**Determine as coordenadas do ponto P, sabendo que ele pertence ao eixo Ox e é equidistante de A(–2, –2) e B(1, 2).**

**Resolução:**
Como P pertence ao eixo Ox, a ordenada de P é 0, portanto P(x, 0).
Como d_PA = d_PB, temos:

[x–(–2)]² + [0–(–2)]² = (x–1)² + (0–2)²
x² + 4x + 4 + 4 = x² – 2x + 1 + 4
6x = –3
x = –1/2

**Logo, o ponto P corresponde ao par ordenado (–1/2, 0).**

## Matemática em questão — A menor distância entre dois pontos é sempre uma reta?

Sabemos que a menor distância entre dois pontos é uma reta — mas isso é válido num plano. Na superfície terrestre (esfera), a menor distância é a **distância geodésica**: a medida do arco formado pelos dois pontos na crosta, que tem formato quase esférico.

## Texto complementar — O baricentro de um triângulo (pág. 359–360)

O **baricentro** G de um triângulo é o ponto onde as três medianas se encontram. Para calcular suas coordenadas analiticamente:

Dado o triângulo ABC com A(x_A, y_A), B(x_B, y_B), C(x_C, y_C):
- M é o ponto médio de BC → x_M = (x_B + x_C)/2
- Como G é baricentro e AM é mediana: AG = 2·GM (Teorema de Tales)
- Desenvolvendo: 3x_G = x_A + 2x_M = x_A + x_B + x_C

**Fórmula do baricentro:**

**x_G = (x_A + x_B + x_C) / 3**

**y_G = (y_A + y_B + y_C) / 3**

> Conclusão: as coordenadas do baricentro são a **média aritmética** das coordenadas dos vértices.
