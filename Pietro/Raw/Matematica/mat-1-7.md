## 2. CONCEITOS E DEFINIÇÕES

**Trinômio quadrado perfeito**
- Definição: expressão algébrica que é o resultado do quadrado de um binômio — pode ser fatorada na forma $$(a + b)^2$$ ou $$(a - b)^2$$.
- Exemplos dados pelo livro:
  - $$x^2 + 4x + 4 = (x + 2)^2$$
  - $$x^2 - 2x + 1 = (x - 1)^2$$
  - $$4x^2 - 12x + 9 = (2x - 3)^2$$
  - $$25x^2 + 60x + 36 = (5x + 6)^2$$
  - $$16x^2 + 96x + 144 = (4x + 12)^2$$
- Reconhecimento: o termo do meio é o dobro do produto das raízes quadradas do primeiro e do terceiro termos.

**Equação produto**
- Definição: equação que pode ser escrita como o produto de dois fatores igual a zero, permitindo determinar as raízes diretamente pela propriedade do produto nulo.
- Notação: se $$(A)(B) = 0$$, então $$A = 0$$ ou $$B = 0$$.
- Exemplo: $$x^2 + 4x + 4 = 0 \Rightarrow (x + 2)^2 = 0 \Rightarrow (x+2)(x+2) = 0 \Rightarrow x = -2$$ (raiz dupla); $$S = \{-2\}$$.

**Fórmula de Bhaskara (forma resolutiva geral)**
- Definição: fórmula que permite determinar as raízes de qualquer equação do 2º grau completa $$ax^2 + bx + c = 0$$ (com $$a \neq 0$$).
- Expressão:
$$x = \frac{-b \pm \sqrt{\Delta}}{2a}$$
- Onde $$\Delta = b^2 - 4ac$$ é o discriminante.
- As duas raízes são:
$$x_1 = \frac{-b + \sqrt{\Delta}}{2a} \qquad x_2 = \frac{-b - \sqrt{\Delta}}{2a}$$
- Condição: $$a \neq 0$$; aplicável a qualquer equação completa do 2º grau.

**Discriminante (Δ)**
- Definição: expressão $$\Delta = b^2 - 4 \cdot a \cdot c$$ que determina a natureza das raízes da equação do 2º grau.
- Análise:
  - $$\Delta > 0$$: a equação do 2º grau tem duas raízes reais distintas.
  - $$\Delta = 0$$: a equação do 2º grau tem duas raízes reais iguais.
  - $$\Delta < 0$$: a equação do 2º grau não possui raízes reais.

**Soma e produto das raízes**
- Se $$x_1$$ e $$x_2$$ são raízes de $$ax^2 + bx + c = 0$$ (com $$a \neq 0$$), então:
  - Soma: $$x_1 + x_2 = -\dfrac{b}{a}$$
  - Produto: $$x_1 \cdot x_2 = \dfrac{c}{a}$$
- Dedução: $$(x - x_1)(x - x_2) = 0 \Rightarrow x^2 - (x_1 + x_2)x + x_1 \cdot x_2 = 0$$; comparando com $$x^2 + \dfrac{b}{a}x + \dfrac{c}{a} = 0$$.
- Escrevendo equação a partir de raízes conhecidas:
  - 1ª estratégia (soma e produto): $$x^2 - Sx + P = 0$$, onde $$S = x_1 + x_2$$ e $$P = x_1 \cdot x_2$$.
  - 2ª estratégia (fatoração): $$(x - x_1)(x - x_2) = 0$$.

**Método de completar quadrados**
- Definição: técnica geométrica/algébrica para resolver equações completas do 2º grau, transformando o membro com a incógnita em um trinômio quadrado perfeito.
- Exemplo: $$x^2 + 4x = 12 \Rightarrow x^2 + 4x + 4 = 16 \Rightarrow (x+2)^2 = 16 \Rightarrow x + 2 = \pm 4 \Rightarrow x = 2$$ ou $$x = -6$$.

**FC-10**

Verso: O termo do meio deve ser o dobro do produto das raízes quadradas do 1º e do 3º termos. Ex.: $$x^2 + 4x + 4$$: $$2 \cdot \sqrt{x^2} \cdot \sqrt{4} = 2 \cdot x \cdot 2 = 4x$$ ✓.

**FC-11**

**FC-12**
Frente: Resolva $$x^2 + 4x + 4 = 0$$ por fatoração.
Verso: $$(x+2)^2 = 0 \Rightarrow x = -2$$ (raiz dupla); $$S = \{-2\}$$.

**FC-13**
Frente: Quem foi Bhaskara e por que é importante para a Matemática?
Verso: Bhaskara (1114–1185), matemático indiano. Desenvolveu a fórmula geral de resolução de equações do 2º grau, utilizada até hoje e conhecida no Brasil como Fórmula de Bhaskara.

**FC-14**
Frente: Como determinar Δ e usar a fórmula para $$4x^2 - 3x - 1 = 0$$?
Verso: $$a=4, b=-3, c=-1$$; $$\Delta = 9+16 = 25$$; $$x = (3 \pm 5)/8$$; $$x_1 = 1$$, $$x_2 = -1/4$$; $$S = \{-1/4, 1\}$$.

**FC-15**
Frente: Qual é a fórmula da diagonal de um polígono em função do número de lados?
Verso: $$d = \dfrac{n(n-3)}{2}$$, onde $$d$$ = diagonais e $$n$$ = lados. Para encontrar $$n$$ dado $$d$$, monta-se equação do 2º grau.

**FC-16**
Frente: Como escrever a equação do 2º grau cujas raízes são $$x_1 = 1$$ e $$x_2 = 2$$ usando as duas estratégias?
Verso: 1ª (S e P): $$S=3$$, $$P=2$$ → $$x^2 - 3x + 2 = 0$$. 2ª (fatoração): $$(x-1)(x-2)=0 \Rightarrow x^2-3x+2=0$$.

## BLOCO B — PROPRIEDADES E REGRAS OPERACIONAIS

**Formas do trinômio quadrado perfeito**
- Enunciado: $$(a + b)^2 = a^2 + 2ab + b^2$$ e $$(a - b)^2 = a^2 - 2ab + b^2$$.
- Aplicação: uma equação completa cujo membro esquerdo é um trinômio quadrado perfeito pode ser resolvida por fatoração direta.

**Análise do discriminante**
- Enunciado: Dado $$\Delta = b^2 - 4ac$$ para a equação $$ax^2 + bx + c = 0$$ ($$a \neq 0$$):
  - Se $$\Delta > 0$$: a equação possui duas raízes reais distintas.
  - Se $$\Delta = 0$$: a equação possui duas raízes reais iguais.
  - Se $$\Delta < 0$$: a equação não possui raízes reais.

**Soma das raízes**
- Enunciado: Se $$x_1$$ e $$x_2$$ são raízes de $$ax^2 + bx + c = 0$$ ($$a \neq 0$$), então $$x_1 + x_2 = -\dfrac{b}{a}$$.
- Expressão simbólica: $$S = -\dfrac{b}{a}$$

**Produto das raízes**
- Enunciado: Se $$x_1$$ e $$x_2$$ são raízes de $$ax^2 + bx + c = 0$$ ($$a \neq 0$$), então $$x_1 \cdot x_2 = \dfrac{c}{a}$$.
- Expressão simbólica: $$P = \dfrac{c}{a}$$

**Equação a partir de raízes conhecidas (1ª estratégia)**
- Enunciado: Conhecendo $$x_1$$ e $$x_2$$, a equação do 2º grau com coeficiente $$a = 1$$ é:
$$x^2 - (x_1 + x_2)x + x_1 \cdot x_2 = 0$$
- Exemplo: raízes $$x_1 = 1$$ e $$x_2 = 2$$ → $$S = 3$$, $$P = 2$$ → $$x^2 - 3x + 2 = 0$$.

**Equação a partir de raízes conhecidas (2ª estratégia)**
- Enunciado: $$(x - x_1)(x - x_2) = 0$$; desenvolvendo chega-se à forma reduzida.
- Exemplo: $$x_1 = 1$$, $$x_2 = 2$$ → $$(x-1)(x-2) = 0 \Rightarrow x^2 - 3x + 2 = 0$$.

## BLOCO C — FÓRMULAS PRINCIPAIS

**Discriminante**
- Expressão: $$\Delta = b^2 - 4 \cdot a \cdot c$$
- Variáveis: $$a$$ = coeficiente do termo quadrático; $$b$$ = coeficiente do termo linear; $$c$$ = termo independente
- Condições: $$a \neq 0$$

**Fórmula de Bhaskara**
- Expressão: $$x = \dfrac{-b \pm \sqrt{\Delta}}{2a}$$
- Variáveis: $$x$$ = incógnita (raízes $$x_1$$ e $$x_2$$); $$\Delta$$ = discriminante; $$a, b, c$$ = coeficientes
- Condições: $$a \neq 0$$; $$\Delta \geq 0$$ para raízes reais
- Caso especial: $$\Delta < 0$$ → sem solução real; $$\Delta = 0$$ → $$x_1 = x_2 = \dfrac{-b}{2a}$$
💡 Pegadinha: o denominador é $$2a$$, não apenas $$2$$ — o coeficiente $$a$$ faz parte do denominador completo.

**Soma das raízes**
- Expressão: $$S = x_1 + x_2 = -\dfrac{b}{a}$$

**Produto das raízes**
- Expressão: $$P = x_1 \cdot x_2 = \dfrac{c}{a}$$

**Fórmula das diagonais de um polígono**
- Expressão: $$d = \dfrac{n(n-3)}{2}$$
- Variáveis: $$d$$ = número de diagonais; $$n$$ = número de lados
- Aplicação inversa: dado $$d$$, monta-se equação do 2º grau em $$n$$ e resolve pela fórmula de Bhaskara (descartando raiz negativa).

## BLOCO E — EXEMPLOS RESOLVIDOS E EXERCÍCIOS DE FIXAÇÃO

**Exercício Resolvido 1 — Trinômio quadrado perfeito**
- Enunciado: Resolva $$4x^2 - 32x + 64 = 0$$ no conjunto $$\mathbb{R}$$.
- Desenvolvimento:
$$4x^2 - 32x + 64 = 0 \Rightarrow (2x - 8)^2 = 0 \Rightarrow (2x-8)(2x-8) = 0$$
Como os dois fatores são iguais, a equação tem duas raízes reais iguais:
$$2x - 8 = 0 \Rightarrow x = 4$$
- Resultado: $$S = \{4\}$$
- Conceito: fatoração por trinômio quadrado perfeito; raiz dupla.

**Exercício Resolvido 2 — Trinômio quadrado perfeito com coeficiente fracionário**
- Enunciado: Resolva $$x^2 + \dfrac{2x}{3} + \dfrac{1}{9} = 0$$ no conjunto $$\mathbb{R}$$.
- Desenvolvimento:
$$\left(x + \dfrac{1}{3}\right)^2 = 0 \Rightarrow x + \dfrac{1}{3} = 0 \Rightarrow x = -\dfrac{1}{3}$$
- Resultado: $$S = \left\{-\dfrac{1}{3}\right\}$$
- Conceito: fatoração por trinômio quadrado perfeito.

**Exercício Resolvido 3 — Fórmula de Bhaskara (exemplo 1)**
- Enunciado: Resolva $$x^2 + 5x + 6 = 0$$ no conjunto $$\mathbb{R}$$.
- Desenvolvimento:
$$a = 1, \quad b = 5, \quad c = 6$$
$$\Delta = 5^2 - 4 \cdot 1 \cdot 6 = 25 - 24 = 1$$
$$x = \frac{-5 \pm \sqrt{1}}{2 \cdot 1} = \frac{-5 \pm 1}{2}$$
$$x_1 = \frac{-5 + 1}{2} = -2 \qquad x_2 = \frac{-5 - 1}{2} = -3$$
- Resultado: $$S = \{-3, -2\}$$
- Conceito: fórmula de Bhaskara; equação completa com $$\Delta > 0$$.

**Exercício Resolvido 4 — Fórmula de Bhaskara (exemplo 2)**
- Enunciado: Resolva $$4x^2 - 3x - 1 = 0$$ no conjunto $$\mathbb{R}$$.
- Desenvolvimento:
$$a = 4, \quad b = -3, \quad c = -1$$
$$\Delta = (-3)^2 - 4 \cdot 4 \cdot (-1) = 9 + 16 = 25$$
$$x = \frac{3 \pm 5}{8}$$
$$x_1 = \frac{3+5}{8} = 1 \qquad x_2 = \frac{3-5}{8} = -\frac{1}{4}$$
- Resultado: $$S = \left\{-\dfrac{1}{4}, 1\right\}$$
- Conceito: fórmula de Bhaskara; atenção ao sinal de $$b$$ negativo no cálculo de $$\Delta$$.

**Exercício Resolvido 5 — Equação sem raízes reais**
- Enunciado: Resolva $$5x^2 - 3x + 2 = 0$$ no conjunto $$\mathbb{R}$$.
- Desenvolvimento:
$$a = 5, \quad b = -3, \quad c = 2$$
$$\Delta = (-3)^2 - 4 \cdot 5 \cdot 2 = 9 - 40 = -31$$
Como $$\Delta < 0$$, não existe valor real para $$\sqrt{-31}$$.
- Resultado: $$S = \emptyset$$
- Conceito: $$\Delta < 0$$ → sem raízes reais.

**Exercício Resolvido 6 — Análise do discriminante (discriminante)**
- Enunciado: Determine quantas raízes reais possuem as equações do 2º grau:
  a) $$x^2 + 3x + 2 = 0$$ b) $$12x^2 - 10x + 8 = 0$$ c) $$-x^2 + 10x - 25 = 0$$
- Desenvolvimento:
  a) $$\Delta = 9 - 4 \cdot 1 \cdot 2 = 1 > 0$$ → duas raízes reais distintas.
  b) $$\Delta = (-10)^2 - 4 \cdot 12 \cdot 8 = 100 - 384 = -284 < 0$$ → não possui raízes reais.
  c) $$\Delta = 10^2 - 4 \cdot (-1) \cdot (-25) = 100 - 100 = 0$$ → duas raízes reais iguais.
- Conceito: análise do discriminante — três casos.

**Exercício Resolvido 7 — Discriminante com parâmetro (para m)**
- Enunciado: Determine os valores de $$m$$ para que $$x^2 - 4x + 3m = 0$$ tenha duas raízes reais distintas.
- Desenvolvimento:
$$\Delta = (-4)^2 - 4 \cdot 1 \cdot 3m = 16 - 12m > 0$$
$$-12m > -16 \Rightarrow m < \dfrac{4}{3}$$
- Resultado: qualquer valor de $$m$$ menor que $$\dfrac{4}{3}$$ faz com que a equação tenha duas raízes reais distintas.

**Exercício Resolvido 8 — Discriminante com parâmetro (para k)**
- Enunciado: Determine o valor de $$k$$ para que $$4x^2 + kx + 200 = 0$$ tenha duas raízes reais iguais.
- Desenvolvimento:
$$\Delta = 0 \Rightarrow k^2 - 4 \cdot 4 \cdot 200 = 0$$
$$k^2 = 3200 \Rightarrow k = \pm\sqrt{3200} = \pm 40\sqrt{2}$$
- Resultado: $$k = 40\sqrt{2}$$ ou $$k = -40\sqrt{2}$$.

## BLOCO F — CONTEXTUALIZAÇÃO REAL E APLICAÇÕES

**O método de completar quadrados: processo geométrico**
- Conexão com o conceito matemático: método geométrico alternativo para resolver equações completas do 2º grau — "completar quadrados".
- Dados e fatos relevantes:
  - O método usa representação geométrica de quadrados e retângulos para transformar a expressão algébrica em trinômio quadrado perfeito.
  - Exemplo apresentado: $$x^2 + 4x = 12$$
    - Adiciona-se 4 a ambos os membros: $$x^2 + 4x + 4 = 12 + 4 = 16$$
    - O lado esquerdo torna-se: $$(x + 2)^2 = 16$$
    - $$(x + 2) = \pm\sqrt{16} = \pm 4$$
    - $$x + 2 = 4$$ ou $$x + 2 = -4$$
    - $$x = 2$$ ou $$x = -6$$
  - O quadrado formado tem lado medindo $$(1 + x + 1)$$, ou seja, $$(x + 2)$$.
- Fonte: Romirys Cavalcante. *Vivendo entre símbolos*, 17 dez. 2013. Disponível em: www.vivendoentresimbolos.com/2013/02/o-metodo-de-completar-quadrados_17.html. Acesso em: 10 ago. 2017.

## BLOCO G — MATEMÁTICA EM QUESTÃO

- Título e tema: **É possível determinar o número de lados do polígono a partir das diagonais?**
- Texto completo:
  Em anos anteriores, você estudou que, para determinar o número de diagonais de um polígono, basta usar a fórmula $$d = \dfrac{n(n-3)}{2}$$, em que $$d$$ representa a quantidade de diagonais, e $$n$$ a quantidade de lados. Mas como podemos descobrir o número de lados de um polígono conhecendo suas diagonais? A resposta é simples: usando uma equação do 2º grau. Observe o exemplo:

  Quantos lados tem um polígono que possui 560 diagonais?

  $$560 = \dfrac{n(n-3)}{2}$$
  $$560 \cdot 2 = n^2 - 3n$$
  $$n^2 - 3n - 1120 = 0$$

  $$x = \frac{-(-3) \pm \sqrt{(-3)^2 - 4 \cdot 1 \cdot (-1120)}}{2 \cdot 1} = \frac{3 \pm \sqrt{9 + 4480}}{2} = \frac{3 \pm \sqrt{4489}}{2} = \frac{3 \pm 67}{2}$$

  $$x_1 = \frac{3 + 67}{2} = 35 \qquad x_2 = \frac{3 - 67}{2} = -32$$

  Como não existem quantidades negativas, $$n = 35$$. Portanto, o polígono tem 35 lados.

## BLOCO H — REFLEXÃO

- Texto da reflexão: [caixa com ponto de interrogação] Você já estudou que, para determinar o conjunto solução de uma equação do 2º grau, é necessário calcular o discriminante (Δ) da equação. Ao calcular $$\Delta = b^2 - 4ac$$, podemos determinar, antes de calcular as raízes, quantas soluções reais a equação possui. Por isso, podemos dizer que a análise do discriminante serve para determinar **quantas** raízes reais uma equação possui — não quais são as raízes.
- Conceito matemático central: distinção entre análise do discriminante (determina quantidade de raízes) e fórmula de Bhaskara (determina os valores das raízes).
- Contexto algébrico: equações completas do 2º grau da forma $$ax^2 + bx + c = 0$$.
